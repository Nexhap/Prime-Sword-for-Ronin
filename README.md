## Manual Installation:
**This assumes you installed the northstar client for your game**
1. Download and extract the zip file   
2. Drop the "Nexhap.PrimeSword" folder into this directory of your game folder:  
<span style="border: 2px solid #D3D3D3; padding: 1px; border-radius: 1px;">
  **Titanfall 2/R2Northstar/mods**
</span>
